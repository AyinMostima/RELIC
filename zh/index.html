RELIC 文档

本站记录可重组生态系统集成耦合库（Recomposable Ecosystem Library for Integrated Coupling, RELIC） 1.0.0 的公开架构与科学契约，涵盖数学基础、全部 90 个已认证具体科学 Functor 类（由 92 份互连端口哈密顿系统（Interconnected Port-Hamiltonian System, IPHS）证书支撑）、运行时工作流、图编排、扩展规则，以及 relic\ 全部 16 个子包的核心 Python API（共 594 个子包 .py 文件，含 relic\__init__.py 共 595 个 Python 文件，316,129 行 Python 代码，七层架构外加一个正交控制平面，以及由 138 个 YAML 文件加载的 4,643 个默认运行时参数）。

页面标题和页脚显示的版本读取自 pyproject.toml 中的 package version。每个章节均受该版本化 architecture contract 及其当前公开 owner 约束。

可执行教程层次

RELIC 提供三个互补的教程层次。三者相互衔接，但用途不同：

  1. 本站 workflow 页面提供可复制运行的小型示例，并给出 signature、预期输出、异常和当前限制。

  2. tutorial\primary 包含 30 个 notebook，依次覆盖环境设置、真实组件、耦合、守恒、校准、Data I/O、surrogate model、ensemble、assimilation 与跨域验证。

  3. tutorial\case 是完整的 Tapajós BVOC 实例，包含 forcing provenance、配置、模拟、监控、checkpoint、评估和图件。它是完整研究案例，不是通用 benchmark dataset。

所有教程采用同一证据模式：预检环境；声明输入与配置；运行有界实例；检查日志和输出；用显式 oracle 或参考值比较数值结果；记录 provenance；说明该运行不能证明什么。仅进程成功退出不构成科学验证。

文档设计参考

本指南按成熟地球系统软件文档方式组织：系统概览、准备、配置、执行、输出、故障排查、科学选项和 benchmark 式教程。WRF Users' Guide 与 CMAQ User's Guide 仅作为组织方式参考。RELIC 的 API、方程、证据等级和 runtime 声明仍由本仓库当前 owner 与测试约束。
