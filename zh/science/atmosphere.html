各表区分 constructor 控制项、runtime variable 与 ParameterManager 科学参数。所示 package default 属于该 RELIC 架构版本，不得复制为科学代码中的硬编码常量。

证书中的通配参数组（*、<pft>）会展开为当前 YAML 中的精确条目。其余声明参数均按完整键与参数数据库精确匹配；不会仅因某个键的后缀与声明名称相同就将两者对应。

IPHS level 只从唯一的 certificate owner 读取。Level 1 至 3 分别表示 compatibility、wrapping 或 declared structure，不构成 strict IPHS/GENERIC 声明。

控制方程与 canonical operator

文献或过程形式

\(A = - \nu ^{\mathsf{T}} \mu\)；\(\mu_{i} = h_{i} ( T ) - T s_{i} ( T ) + R T \ln ( p_{i} / \mathrm{p0} )\)；\(\sigma = A r / T \geq 0\)；\(\dot{x} = L_{h} e_{E} + M_{h} e_{S}\)，其中 \(L_{h} = 0\) 且 \(M_{h} = ( r T / A ) \nu \nu ^{\mathsf{T}} ( \mathrm{Grmela} \mathrm{and} \mathrm{Ottinger} 1997 ; \mathrm{Mielke} 2011 ; \mathrm{Kondepudi} \mathrm{and} \mathrm{Prigogine} 1998 )\)

Canonical RELIC 结构形式

\(\dot{x} = L_{h} e_{E} + M_{h} e_{S}\)，\(L_{h} = 0 ( \mathrm{zero}_{\mathrm{field}} )\)，\(M_{h} = ( r T / A ) \nu \nu ^{\mathsf{T}}\)，absorbed 反应，其 \(M_{h} e_{S} = N r \mathrm{checked} \mathrm{against} \mathrm{the}\) 已声明的 N r，\(M_{h} e_{E} = 0\)

条目

含义

L_h

通过 \(\mathrm{poisson}_{\mathrm{operator}} = \mathrm{zero}_{\mathrm{field}}\) 声明的零 Poisson 算子；Jacobi 恒等式在由 IPHSStructureSpec.validate 验证的规范零场基上成立

M_h

(r T / A) nu nu^T，在 \(A > 0\) 且 \(r \geq 0\) 时对称正半定，其能量行与能量列为零，因此 \(M_{h} e_{E} = 0\)

G_h

无；无 port 的封闭箱

N

\(\nu = ( - 1 , + 1 , - 1 , + 1 , 0 ) \mathrm{reshaped}\) 重塑为 5 乘 1；\(\mathrm{reaction}_{\mathrm{representation}} = \mathrm{absorbed}\)，因此 N r 不会被第二次加入

状态推进、守恒与开放边界

条目

含义

potential_basis

\(E = U\) 与 S(U, n, V) 由 standard_molar_properties、ideal_gas_mixture_properties 和 temperature_from_internal_energy 在同一 autograd 状态图上求值

effort_variable

\(e_{E} = \nabla ( E ) = ( 0 , 0 , 0 , 0 , 1 )\) 与 \(e_{S} = \nabla ( S ) = ( - \mu / T , 1 / T ) \mathrm{obtained}\) 由 canonical_drift 内部的 torch.autograd.grad 获得

state_advancer

\(\Delta x = \mathrm{d}t \dot{x}\)，其中 \(\dot{x} = L_{h} e_{E} + M_{h} e_{S} = \nu r\)；实际张量候选 x + Delta x 在发出前必须保持所有物种库存严格为正，\(T ( U, n )\) 有效，理想混合物性质处于合法定义域内，并满足 \(A > 0\)

explicit_stoichiometric_usage

forward 声明 \(\mathrm{stoichiometric}_{N} = \nu \mathrm{reshaped}\) 为 5 乘 1，并带有 \(\mathrm{reaction}_{\mathrm{representation}} = \mathrm{absorbed} \mathrm{in} \mathrm{IPHSStructureSpec}\)；同时将相同的 N、反应速率、\(C_{N}\)、\(C_{O}\) 与 affinity 以 \(\mathrm{d}t = \mathrm{None}\) 传入 advance_reaction_network，仅用于审计。

runtime_usage

ChemistryFunctor.forward 通过 canonical_drift 计算唯一的 GENERIC absorbed-reaction 路径，在归约舍入误差范围内核验 \(M_{h} e_{S} = N r\)，用已绑定的步前运行点验证 \(\mathrm{required}_{\mathrm{level}} = 5\)，并审计 \(C_{N} \nu = 0\)、\(C_{O} \nu = 0\) 与 \(A r \geq 0\)；在发布审计或发出五个 ACCUMULATE 增量和八个 REPLACE 诊断量之前，同一纯热力学性质所有者检查实际张量 Euler 候选是否满足 \(n_{i} > 0\)、有效的 \(T ( U, n )\) 及 \(A > 0\)，不另算第二个 drift 或推进状态。离散熵单调性、刚性稳定性与精度尚未认证。
