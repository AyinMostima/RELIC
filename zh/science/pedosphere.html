控制方程与 canonical operator

文献或过程形式

\(\frac{\mathrm{d}C}{\mathrm{d}t} = I + T \cdot K \cdot C - \operatorname{diag} ( K ) \cdot C\)，并满足质量平衡

Canonical RELIC 结构形式

\[ \dot{x}=N_h r_h \]

其中过程速率 \(r_h\) 由 ParameterManager 支撑，\(N_h\) 为已声明的 stoichiometric/output map

条目

含义

N_h

显式五库区室 incidence map 加开放异养呼吸出口；此 level-2 wrapper 不构成 strict stoichiometric 声明

r_h

由生产 forward 路径评估的 ParameterManager 支持的总衰减、传输、边界输入和呼吸速率向量

boundary_route

五个已声明的碳库输入 ports 提供碳，heterotrophic_respiration 输出碳

状态推进、守恒与开放边界

条目

含义

potential_basis

已声明的 RELIC state、port 或 observation cochain basis

effort_variable

经验外部环境调节剂；未声明 Hamiltonian effort

state_advancer

\(\dot{x} = N_{h} r_{h}\)；compartment incidence matrix 与 rate vector 由 advance_reaction_network 求值

runtime_usage

PoolsMatrix.forward 通过 advance_reaction_network 恰好一次求值五个 net pool tendencies 与 open respiration export，随后将 StateManager 可表示的 increment (C + Delta_C_raw) - C 同时用于 UpdateItem values 与 carbon ledger。

explicit_stoichiometric_usage

隔室关联图是显式的 level-2 运行时结构，并且不是 Hamiltonian 或 GENERIC 闭包的证据。

控制方程与 canonical operator

文献或过程形式

带阻滞的 Freundlich 平衡吸附 (Jury and Horton 2004; Mayes et al. 2012) 与一阶溶解相降解；采用代数消元的半显式 index-1 DAE (Hairer and Wanner 1996)

Canonical RELIC 结构形式

\(E \dot{x} = f ( x )\)，\(g ( x ) = 0\)，其中 \(x = ( y , C , S )\)，\(E = \operatorname{diag} ( 1 , 0 , 0 )\)，\(g = ( \theta C + \rho_{b} S - y , S - K_{f} C ^ n )\)；\(g_{z}\) 可逆 (index 1)

条目

含义

constraint

\(g ( y , C ) = \theta C + \rho_{b} K_{f} C ^ n - y\)，其中 \(g_{C} = \theta + \rho_{b} K_{f} n C ^ ( n - 1 ) > 0 ( \mathrm{index} 1 )\)

elimination

标量单调方程 \(F ( C ' ) = \theta C ' + \rho_{b} K_{f} C ' ^ n + \mathrm{d}t \lambda \theta C ' - y \mathrm{solved}\) 由现有的 BracketedBisectionSolver 在精确区间 [0, y/theta] 上求解

differential_update

隐式 Euler y' = y - dt lambda theta C'

restart_projection

所存储的 (y, C, S) 三元组在每一步都重新验证一致性，因此恢复的 checkpoint 在推进之前会由同一检查重新投影

状态推进、守恒与开放边界

条目

含义

potential_basis

单元基上的微分总质量 y，以及约束流形上的代数对 (C, S)；不声明 storage functional

effort_variable

none；分配关系与等温线是代数约束，而非变分 efforts

state_advancer

y' = y - dt lambda theta C'，其中 C' 来自隐式约束的区间求解，且 S' = \(K_{f}\) C'^n

runtime_usage

EquilibriumSorptionFunctor.forward 验证状态与含水量，拒绝不一致的三元组，使用 BracketedBisectionSolver 求解标量约束，在不收敛时抛出异常，发出一个 ACCUMULATE 增量、两个 REPLACE 代数状态和三个 REPLACE diagnostics，并通过 check_conservation_laws 报告总质量 ledger 残差。
