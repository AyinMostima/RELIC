通用 Transport 科学类

本参考覆盖 relic.scientific.transport 中全部 4 个 certificate-backed scientific class：4 个可执行 concrete Functor、0 个 fail-closed 不可用边界与 0 个 abstract contract。每个条目均依据 live class、IPHS certificate、State Contract Model 与 ParameterManager metadata 生成。文档生成期间不会实例化 fail-closed 不可用类。

各表区分 constructor 控制项、runtime variable 与 ParameterManager 科学参数。所示 package default 属于该 RELIC 架构版本，不得复制为科学代码中的硬编码常量。

证书中带通配符的参数组（*、<pft>）会展开为当前 YAML 中的精确条目。其他声明参数均按完整键名与参数数据库精确匹配；不会将声明名称映射到仅以相同名称结尾的键。

精确匹配的 ParameterManager 行展示当前 YAML 值、边界、梯度策略、说明和来源。值标为 not declared in the parameter database 的行不会被赋予编造的默认值：类元数据或证书声明了该量及其含义和单位，但参数数据库中没有完全同名的键。

IPHS level 只从唯一的 certificate owner 读取。Level 1 至 3 分别表示 compatibility、wrapping 或 declared structure，不构成 strict IPHS/GENERIC 声明。

各运行时输出契约的通道列将唯一的运行时输出通道分类器 relic.core.state.types.partition_outputs 应用于声明的输出名称。分类器保留给诊断的名称（如 diagnostics.*）进入诊断通道，不会作为状态提交。其他名称的通道由返回值的写入模式在运行时决定：StateWriteMode.DERIVED 将输出送入诊断通道，其他写入模式则将其送交 StateManager 提交（没有写入模式的值遵循本次运行的语义模式规则或 StateManager 模式）。生成器不执行 forward()，因此不会预测该写入模式。种类列表示变量在状态契约模型中的种类，不决定其通道。

控制方程与 canonical operator

文献或过程形式

守恒形式的平流-扩散，其中 \(q_{\mathrm{adv}} = v c\)、\(q_{\mathrm{diff}} = - K \nabla ( c )\)，且 \(\frac{\mathrm{d}c}{\mathrm{d}t} = - \operatorname{div} ( q_{\mathrm{adv}} + q_{\mathrm{diff}} ) + S .\)

Canonical RELIC 结构形式

\[ \dot{c} = - D_{h} ( q_{\mathrm{adv},h} + q_{\mathrm{diff},h} ) + G_{h} u_{h}; q_{\mathrm{adv},h} = i_{v} c_{h}; q_{\mathrm{diff},h} = - \star_{K} d_{h} c_{h} . \]

条目

含义

D_h

既有规范 finite-volume advection_diffusion divergence stencil

i_v

AdvectionDiffusion 的 advective HodgeStarSpec 与 functional flux operator

star_K

AdvectionDiffusion 的 diffusive HodgeStarSpec 与 functional flux operator

splitting

统一 advection_diffusion operator 中既有的 splitting_method

transport.numerical.implicit_midpoint_max_iter

dimensionless

50; bounds=(1.0, 100.0)

fixed

隐式中点和 Crank-Nicolson 输运步的最大不动点（Picard）迭代次数（functional._integrate_rate_system）；耗尽次数会抛出 RuntimeError，不会返回未收敛状态。映射 y <- y_n + dt f((y_n + y)/2)（Crank-Nicolson 的 theta = 1/2）的压缩因子为 q = (dt/2) L，其中 L 是半离散速率在无穷范数下的 Lipschitz 常数，因此约 ln(tol)/ln(q) 次迭代可达到增量容差 transport.numerical.implicit_midpoint_tolerance（1e-10）。中心平流的 L = |u|/dx、迎风平流的 2|u|/dx 和扩散的 4K/dx^2 分别给出 q = C/2、C 和 2 sigma（C = |u| dt/dx，sigma = K dt/dx^2）。50 次可覆盖 q <= 0.6：中心平流覆盖文档所列完整范围 C <= transport.numerical.cfl_advection_max = 1，迎风平流覆盖至 C = 0.6，扩散覆盖至 sigma = 0.3（2026-09-23 的 64 单元周期阶跃剖面探针，两种方法均测试：中心平流 C = 1 时最多 30 次，迎风平流 C = 0.6 和扩散 sigma = 0.3 时最多 41 次）。q >= 1 时（迎风平流 C = 1，扩散 sigma = transport.numerical.cfl_diffusion_max = 0.5），无论上限设多大，迭代都无法收敛，时间步会报错；应减小 dt。此值于 2026-09-23 从 4 改为 50：4 次仅在 q 不超过约 0.01 时收敛（例如中心平流在 C = 0.1 时失败，需要 8 次）；已收敛时间步的结果不变，因为迭代返回首次收敛结果。它不同于 computation.solvers.implicit_midpoint.max_iterations 和 computation.solvers.crank_nicolson.max_iterations，后两者是求解器为未传入配置的调用方提供的默认值；输运内核始终显式传入此值。

控制方程与 canonical operator

文献或过程形式

守恒形式的 Fick 扩散，其通量为 \(J = - D \nabla ( c )\)，储量趋势为 \(\frac{\mathrm{d}c}{\mathrm{d}t} = - \operatorname{div} ( J ) + S\)；封闭 finite-volume 形式 \(\frac{\mathrm{d}H}{\mathrm{d}t} = - \sum_{f} K_{f} ( \frac{\mathrm{d}c_{f}}{\mathrm{d}x} ) ^ 2 \leq 0\) 对 \(H = 0.5 \mathtt{c.c} ( \mathrm{Crank} 1975 ; \mathrm{Patankar} 1980 ; \mathrm{van} \mathrm{der} \mathrm{Schaft} \mathrm{and} \mathrm{Jeltsema} 2014 )\) 成立

Canonical RELIC 结构形式

\[ \dot{c} = ( J_{h} - R_{h} ) e_{H}; J_{h} = 0; R_{h} = d_{h} ^{\mathsf{T}} \operatorname{diag} ( K_{f} ) d_{h} / \mathrm{d}x ^ 2; e_{H} = c_{h}; \frac{\mathrm{d}H_{h}}{\mathrm{d}t} = - e_{H} ^{\mathsf{T}} R_{h} e_{H} \leq 0 \]

transport.numerical.implicit_midpoint_max_iter

dimensionless

50; bounds=(1.0, 100.0)

fixed

隐式中点和 Crank-Nicolson 输运步的最大不动点（Picard）迭代次数（functional._integrate_rate_system）；耗尽次数会抛出 RuntimeError，不会返回未收敛状态。映射 y <- y_n + dt f((y_n + y)/2)（Crank-Nicolson 的 theta = 1/2）的压缩因子为 q = (dt/2) L，其中 L 是半离散速率在无穷范数下的 Lipschitz 常数，因此约 ln(tol)/ln(q) 次迭代可达到增量容差 transport.numerical.implicit_midpoint_tolerance（1e-10）。中心平流的 L = |u|/dx、迎风平流的 2|u|/dx 和扩散的 4K/dx^2 分别给出 q = C/2、C 和 2 sigma（C = |u| dt/dx，sigma = K dt/dx^2）。50 次可覆盖 q <= 0.6：中心平流覆盖文档所列完整范围 C <= transport.numerical.cfl_advection_max = 1，迎风平流覆盖至 C = 0.6，扩散覆盖至 sigma = 0.3（2026-09-23 的 64 单元周期阶跃剖面探针，两种方法均测试：中心平流 C = 1 时最多 30 次，迎风平流 C = 0.6 和扩散 sigma = 0.3 时最多 41 次）。q >= 1 时（迎风平流 C = 1，扩散 sigma = transport.numerical.cfl_diffusion_max = 0.5），无论上限设多大，迭代都无法收敛，时间步会报错；应减小 dt。此值于 2026-09-23 从 4 改为 50：4 次仅在 q 不超过约 0.01 时收敛（例如中心平流在 C = 0.1 时失败，需要 8 次）；已收敛时间步的结果不变，因为迭代返回首次收敛结果。它不同于 computation.solvers.implicit_midpoint.max_iterations 和 computation.solvers.crank_nicolson.max_iterations，后两者是求解器为未传入配置的调用方提供的默认值；输运内核始终显式传入此值。

来源：RELIC 输运模块；Hairer et al. (2006) Geometric Numerical Integration；Hairer, E. and Wanner, G. (1996) Solving Ordinary Differential Equations II, 2nd ed., Springer, Sec. IV.8（隐式 Runge-Kutta 方程的不动点迭代）
