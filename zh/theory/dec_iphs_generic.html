DEC、IPHS、GENERIC、端口与反应结构

结构治理生命周期

本构速率公式规定局地条件下的过程速率；结构治理在此基础上进一步规定离散空间支撑域、守恒元素账本、共轭热力学势（effort）、端口功率交换以及溢出残差路由（书稿《生态学分析方法》第 8、9、12 及 13 章）。在可重组生态系统集成耦合库（Recomposable Ecosystem Library for Integrated Coupling, RELIC）中，离散外微分（Discrete Exterior Calculus, DEC）、互连端口哈密顿系统（Interconnected Port-Hamiltonian System, IPHS）与广义非平衡可逆-不可逆耦合方程（General Equation for Non-Equilibrium Reversible-Irreversible Coupling, GENERIC）算子直接在单一运行时生命周期之上增强结构约束，不额外引入第二套模拟器、状态管理器或注册表：

\[ \text{Scientific ABC} \;\Longrightarrow\; \text{Canonical Bridge} \;\Longrightarrow\; \texttt{FunctorBase} \;\Longrightarrow\; \texttt{ParameterManager} + \texttt{StateManager} \;\Longrightarrow\; \text{DEC / IPHS / GraphIR Audit}. \]

每次图中间表示（GraphIR，relic.orchestration.graph_ir）编译遍（relic.orchestration.compiler 中的 compile_graph）均输出规范化的 13 键 report.audit 审计摘要（syntax_ok、semantic_ok、assertion_ok、assertion_audit、conservation_audit、port_matching_audit、overflow_routing_audit、equivalence_certificate_audit、reaction_network_audit、integration_plan_audit、global_compile_audit、validation_error_count、validation_warning_count）。软件接线零空间向量（relic.orchestration.topology_algebra 中的 topology_signature.conservation_vectors）仅概括拓扑关联核空间 \(\ker(\mathbf{B}^{\mathsf{T}})\)，绝不替代经由 StateManager 提交的物理质量守恒或能量守恒。

离散外微分（relic.computation.operators.dec）

拓扑边界参与角色

上边缘正合性与斯托克斯（Stokes）配对

离散外导数 \(D_k: C^k(K) \rightarrow C^{k+1}(K)\) 为链边缘关联矩阵的转置 \(D_k = \partial_{k+1}^{\mathsf{T}}\)，满足精确的拓扑幂零恒等式（书稿《生态学分析方法》第 8 章）：

\[ D_{k+1} D_k = 0, \qquad \langle D_k \alpha,\; c \rangle = \langle \alpha,\; \partial_{k+1} c \rangle. \]

cochain_complex_check（relic.validation.framework.rules.dec_complex）对照 validation.dec_complex.cochain_residual_tolerance 校验 \(D_{k+1} D_k = 0\)（严格校验同时要求关联矩阵元素为整数、满足 \(D_0 \mathbf{1} = 0\) 且边界子复形闭合）。typed_stokes_audit（relic.computation.operators.dec.complex）在给定的上链/链向量上计算离散斯托克斯配对，作为有限点检验。

线性链映射（LinearChainMap）

LinearChainMap（relic.computation.operators.dec.chain_map）表示在已声明的 source 与 target CochainSpaceSpec 上链空间之间带有正单位换算因子 \(u > 0\) 的单位感知线性算子 \(M \in \mathbb{R}^{n_t \times n_s}\)。构造阶段（__post_init__）强制执行四项故障封闭检查：

  1. 二维矩阵阶数：matrix.ndim == 2；

  2. 自由度形状精确匹配：tuple(matrix.shape) == (target.n_dofs, source.n_dofs)；

  3. 矩阵元素全部有限：torch.isfinite(matrix).all()；

  4. 单位缩放因子严格为正：unit_factor > 0.0。

算子作用、复合运算、经单位换算的守恒账本保持（preserves_ledger，对照 validation.iphs.chain_map_ledger_tolerance）、扰动误差上界（error_bound）以及算子距离（distance、close_within）满足：

\[ y = u M x, \qquad \max_{i,j}\lvert \left(C_t (u M) - C_s\right)_{ij} \rvert \le \varepsilon_{\mathrm{cm}}, \qquad \lVert u M \delta x \rVert_2 \le \lVert u M \rVert_2\,\lVert \delta x \rVert_2, \]
\[ d(M_1, M_2) = \lVert u_1 M_1 - u_2 M_2 \rVert_2. \]

精确相等 equals（空间与 unit_factor 一致且 \(d = 0\)）构成等价关系；容差邻近 close_within（\(d(M_1, M_2) \le \varepsilon\)）满足自反性与对称性，不具传递性。上边缘交换关系 \(P_{k+1} D_k^{(a)} = D_k^{(b)} P_k\) 由 chain_map_check（relic.validation.framework.rules.chain_map）独立审计。

霍奇星算子与本构度量（HodgeStarSpec）

HodgeStarSpec（relic.computation.operators.dec.hodge）将原始 \(k\)-上链映射为对偶 \((n - k)\)-上链 \(\star_k: C^k(K) \rightarrow C^{n-k}(K^\ast)\)，并经由受 ParameterManager 中 parameter_keys 与 metric_keys 支撑的矩阵 \(H_k\) 诱导离散内积 \(\langle \alpha, \beta \rangle_k = \alpha^{\mathsf{T}} H_k \beta\)。调用 HodgeStarSpec.validate() 与 hodge_psd_check（relic.validation.framework.rules.hodge）可校验定义域/陪域空间相容性、元素有限性以及按角色区分的正定/半正定性质：

\[ H_k = H_k^{\mathsf{T}}, \qquad z^{\mathsf{T}} H_k z > 0 \quad \forall z \neq 0 \;\; (\text{metric SPD}), \qquad z^{\mathsf{T}} H_k z \ge 0 \;\text{with}\; H_k K = 0,\; \dim K = \operatorname{nullity}(H_k) \;\; (\text{material PSD}). \]

奇异本构材料算子必须提供完整的线性无关核空间基 kernel_basis \(K\)，绝不可替代可逆度量霍奇星算子。给定存储上链 \(x\) 与通量上链 \(f\)，半离散守恒输运方程 \(\frac{\mathrm{d}x}{\mathrm{d}t} = -D^{\mathsf{T}} f + s + b\) 通过 typed_cochain_delta_to_update_item（relic.computation.operators.dec.adapters）降阶为受控的 StateManager 更新记录。

不可逆端口哈密顿与 GENERIC 降阶

IPHSStructureSpec、PortSpecIPHS、assemble_iphs_structure、advance_reaction_network 与 poisson_jacobi_residual（relic.computation.operators.iphs）将耗散端口哈密顿系统（dissipative Port-Hamiltonian, dPH；dissipative_ph）实现同 GENERIC / 度量辛（generic）实现严格分离，绝不混用能量阻尼矩阵 \(R_h\) 与熵迁移率矩阵 \(M_h\)（书稿《生态学分析方法》第 9、12 及 13 章）。

耗散端口哈密顿（dissipative_ph）实现

对于存储泛函 \(H(x)\) 及其共轭势 \(e_H = \nabla_x H(x)\)、端口输入 \(u_h\)、端口矩阵 \(G_h\) 与共轭输出 \(y_h = G_h^{\mathsf{T}} e_H\)，由 IPHSStructureSpec.canonical_drift 求值的规范 dissipative_ph 漂移项（M_h = 0）为：

\[ \frac{\mathrm{d}x}{\mathrm{d}t} = (J_h - R_h) e_H + G_h u_h + N_h r_h, \qquad J_h^{\mathsf{T}} = -J_h, \qquad R_h = R_h^{\mathsf{T}} \succeq 0. \]

由于狄拉克结构反对称互连项满足 \(e_H^{\mathsf{T}} J_h e_H = 0\)，封闭无反应轨迹满足瑞利耗散不等式 \(\frac{\mathrm{d}H}{\mathrm{d}t} = -e_H^{\mathsf{T}} R_h e_H \le 0\)，开放轨迹满足供给率不等式 \(\frac{\mathrm{d}H}{\mathrm{d}t} = -e_H^{\mathsf{T}} R_h e_H + y_h^{\mathsf{T}} u_h \le y_h^{\mathsf{T}} u_h\)。

GENERIC / 度量辛（generic）实现与雅可比基

对于总能量 \(E(x)\)（\(e_E = \nabla_x E\)）与熵 \(S(x)\)（\(e_S = \nabla_x S\)），由 IPHSStructureSpec.canonical_drift 求值并经 IPHSStructureSpec.validate 审计的规范 generic 度量辛漂移项（R_h = 0）为：

\[ \frac{\mathrm{d}x}{\mathrm{d}t} = J_h(x)\,e_E + M_h(x)\,e_S + G_h u_h + N_h r_h, \]

受反对称性、半正定性及互退化条件约束：

\[ J_h^{\mathsf{T}} = -J_h, \qquad M_h = M_h^{\mathsf{T}} \succeq 0, \qquad J_h e_S = 0, \qquad M_h e_E = 0, \qquad e_S^{\mathsf{T}} M_h e_S \ge 0. \]

对于孤立无反应系统（\(u_h = 0\)，\(r_h = 0\)），总能量严格守恒（\(\frac{\mathrm{d}E}{\mathrm{d}t} = e_E^{\mathsf{T}} J_h e_E + e_E^{\mathsf{T}} M_h e_S = 0\)），熵单调不减（\(\frac{\mathrm{d}S}{\mathrm{d}t} = e_S^{\mathsf{T}} M_h e_S \ge 0\)）。RELIC 通过 IPHSStructureSpec.canonical_drift 与 advance_reaction_network 对 GENERIC/度量辛倾向项进行降阶（[I]），未暴露独立的度量辛时间积分器类（[N]）。

\(J_h\)（承载泊松算子 \(L_h\)）的反对称性不足以蕴含雅可比恒等式。IPHSStructureSpec 支持三类对照 validation.iphs.jacobi_tolerance 审计的可执行 poisson_operator 基：

  1. "zero_field"：恒有 \(L(x) = 0\)（canonical_zero_field）；现行全部已认证生产过程均采用零可逆泊松场。

  2. "constant_field"：满足 \(\partial_l L_{ij} = 0\) 的常值反对称矩阵 \(L\)，其雅可比残差恒为零（constant_field_exact）。

  3. "state_field"：可导入的可调用对象 \(L(x)\)，通过自动微分经由 poisson_jacobi_residual 在已声明的 poisson_domain 状态样本集及绑定的等级 5 运行时点上进行审计（sampled_domain_jacobi_residual）：

\[ R_{ijk}(x) = \sum_{l} \left( L_{il}\frac{\partial L_{jk}}{\partial x_l} + L_{jl}\frac{\partial L_{ki}}{\partial x_l} + L_{kl}\frac{\partial L_{ij}}{\partial x_l} \right). \]

静态 matrix_snapshot 张量不携带导数信息，针对状态依赖的雅可比恒等式声明将按故障封闭拒绝（[N]）。

反应网络、开放系统路由与端口互连

advance_reaction_network（relic.computation.operators.iphs）与 reaction_network_check（relic.validation.framework.rules.reaction_network）共同治理化学计量动力学 \(\dot{x}_{\mathrm{rxn}} = N_h r_h\)（\(N_h \in \mathbb{R}^{n_s \times n_r}\)，\(r_h \in \mathbb{R}^{n_r}\)）：

  • 独立反应表示与吸收式反应表示：在同一个 IPHSStructureSpec 中，化学反应要么以显式项 \(+N_h r_h\) 给出（对总能量要求 \(e_H^{\mathsf{T}} N_h r_h = 0\)，对自由能要求 \(\le 0\)），要么吸收至耗散算子内部（在 dissipative_ph 中满足 \(N_h r_h = -R_h e_H\)，在 generic 中满足 \(N_h r_h = M_h e_S\)，此时省略 \(+N_h r_h\) 以杜绝速率重复计入）。

  • 化学计量闭合与物理亲和势功率：内部守恒要求满足 \(C_h N_h = 0\)（以及可选的电中性条件 \(z_h^{\mathsf{T}} N_h = 0\)）。给定化学势 \(\mu\)，反应亲和势 \(\mathcal{A} = -N_h^{\mathsf{T}} \mu\) 满足耗散功率非负条件 \(P_{\mathrm{rxn}} = \mathcal{A}^{\mathsf{T}} r_h \ge 0\)；仅当绑定了可执行正温度 \(T > 0\) 与热力学本构闭合时，除以温度所得的 \(\sigma_{\mathrm{rxn}} = \mathcal{A}^{\mathsf{T}} r_h / T\) 才构成熵产生率。

  • 开放系统交换与溢出路由：开放系统保持内部化学计量闭合（\(C_h N_h = 0\)），并将外部交换单独路由为 \(\frac{\mathrm{d}x}{\mathrm{d}t} = N_h r_h + q_{\mathrm{open}}\)，其中 \(C_h q_{\mathrm{open}} = \dot{\ell}_{\mathrm{open}}\) 通过 OpenSystemRoute（"port"、"boundary_export"、"managed_export"、"diagnostic_residual" 或 "observation"）执行类型化声明。任何边界截断残差 \(r_{\mathrm{clip}} = (x + \Delta x) - \operatorname{clip}(x + \Delta x, x_{\min}, x_{\max})\) 均须在 overflow_routing_check 中声明合法路由（"storage"、"boundary_outflow"、"managed_export"、"diagnostic_residual" 或 "rejected_step"）。

  • 静态端口匹配与运行时端口功率：port_matching_check（relic.validation.framework.rules.port_matching）校验静态端口声明（势/流单位关系 \([P] = [e][f]\)、维数、定向以及带符号关联平衡 \(\sum_i s_i w_i = 0\)）。反对称互连 \(C = -C^{\mathsf{T}}\) 诱导端口互连矩阵 \(J_{\mathrm{port}} = G_h C G_h^{\mathsf{T}}\)，无源反馈 \(u_{\mathrm{int}} = -D y_h\)（\(D \succeq 0\)）仅在 dissipative_ph 模式下诱导端口阻尼 \(R_{\mathrm{port}} = G_h D G_h^{\mathsf{T}}\)（绝不直接叠加至 GENERIC 迁移率矩阵 \(M_h\)）。实际功率平衡 \(P_a + P_b \le 0\) 属于运行时求值（port_power_units_check / feedback_power_ledger），同静态接线检查相区分。
