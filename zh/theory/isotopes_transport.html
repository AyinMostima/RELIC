稳定同位素与一般输运理论

范围、组件清单与证书映射

本页综合阐述两个跨领域 RELIC 软件包（《生态学分析方法》第 23、25 与 26 章）：

  1. 稳定同位素分馏与账本生命周期（relic.scientific.isotopes）：无状态精确拆分二元分馏计算器（[I]）、故障封闭 Level 0 运行时边界 IsotopeHeartbeatFunctor（[N]），以及已退役遗留库追踪器状态（[X]）。

  2. 一般连续介质与离散上链输运（relic.scientific.transport）：有限体积迎风平流、菲克扩散（涵盖 Level 3 开放边界模式及其 Level 4 封闭一维耗散端口哈密顿系统（dissipative Port-Hamiltonian, dPH）运行时点），以及算子分裂平流-扩散。

在这两个软件包中，4 个具体科学 Functor 共持有 5 份互连端口哈密顿系统（Interconnected Port-Hamiltonian System, IPHS）声明式 IPHSEquivalenceCertificate 证书文件（4 份主类证书外加 FickianDiffusion 上的一份 Level 4 构造条件次级证书）：

稳定同位素比值、精确二元分馏与故障封闭账本状态

同位素比值、丰度分数与千分偏差记号

对于重同位素量 \(M_h \ge 0\) 且轻同位素量严格为正 \(M_l > 0\) 的二元稳定同位素对（例如 \(^{13}\mathrm{C}/^{12}\mathrm{C}\)、\(^{15}\mathrm{N}/^{14}\mathrm{N}\) 或 \(^{18}\mathrm{O}/^{16}\mathrm{O}\)），其同位素比值 \(R\)、重/轻同位素丰度分数 \((x_h, x_l)\) 以及相对于国际标准参考比值 \(R_{\mathrm{std}}\)（维也纳皮迪箭石（Vienna Pee Dee Belemnite, VPDB）、大气氮 AIR-\(\mathrm{N}_2\) 或维也纳标准平均大洋水（Vienna Standard Mean Ocean Water, VSMOW）；Fry, 2006；Sharp, 2017）的千分偏差值 \(\delta\) 满足

\[ R = \frac{M_h}{M_l}, \qquad x_h = \frac{M_h}{M_h + M_l} = \frac{R}{1 + R}, \qquad x_l = \frac{M_l}{M_h + M_l} = \frac{1}{1 + R}, \qquad \delta = \left(\frac{R}{R_{\mathrm{std}}} - 1\right)\times 1000\quad [\text{per mil}]. \]

由于 \(\delta\) 属于非线性比值变换而不具备广延可加性，混合两个储库 \(A\) 与 \(B\) 时须分别守恒重同位素质量与轻同位素质量（\(M_h = M_{h,A} + M_{h,B}\)，\(M_l = M_{l,A} + M_{l,B}\)）；对 \(\delta\) 做总质量加权平均仅在稀有丰度极限（小 \(R\)）下构成近似。当轻同位素分母为零或负值时，计算器直接抛出定义域错误，绝不通过任意正则化项掩盖枯竭状态。

无状态精确二元有理分馏计算器（[I]）

relic.scientific.isotopes.fractionation 实现了无状态计算工具类（IsotopeFractionationCalculator、Carbon13FractionationCalculator、Nitrogen15FractionationCalculator 与 Oxygen18FractionationCalculator，状态均为 [I]）。给定产物相对于底物的分馏系数 \(\alpha = R_p / R_s > 0\)（对应千分富集系数 \(\varepsilon = (\alpha - 1)\times 1000\) 以及动力学同位素效应（Kinetic Isotope Effect, KIE）\(\mathrm{KIE} = k_l / k_h\)），离开同位素比值为 \(R_s\) 的供体库的总元素通量 \(F\) 携带产物比值 \(R_F = \alpha R_s\)，并通过 精确二元有理分馏公式 拆分：

\[ F_h = F\,\frac{\alpha R_s}{1 + \alpha R_s}, \qquad F_l = F\,\frac{1}{1 + \alpha R_s}, \qquad F_h + F_l = F. \]

不同于痕量丰度线性近似 \(F_h \approx \alpha R_s F\)，精确有理拆分对一切 \(R_s \ge 0\) 与 \(\alpha > 0\) 均恒等保持总元素质量守恒 \(F_h + F_l = F\)。该组计算器还提供剩余底物比例 \(f \in (0, 1]\) 下的封闭系统瑞利底物演化关系 \(R(f)/R_0 = f^{\alpha - 1}\)、Farquhar et al. (1982) 的 \(\mathrm{C_3}\) 光合作用 \(^{13}\mathrm{C}\) 同位素判别式

\[ \Delta_{\mathrm{C_3}} = a + (b - a)\,\frac{c_i}{c_a}, \]

Mariotti et al. (1981) 的氮动力学分馏关系式，以及 Craig and Gordon (1965) 的蒸发水汽 \(^{18}\mathrm{O}\) 同位素比闭合方程

\[ R_E = \frac{R_L / \alpha_{\mathrm{eq}}(T) - h\,R_A - \varepsilon_k R_L}{1 - h + \varepsilon_k}. \]

故障封闭 IsotopeHeartbeatFunctor（[N]）与已退役 MultiIsotopePoolTracker（[X]）

跨任意 Functor 计算图的预报型多库同位素状态耦合在完整组件 UpdateItem 绑定、父过程所有权以及检查点重放契约完成接线前，统一保持故障封闭：

  • relic.scientific.isotopes.functor.IsotopeHeartbeatFunctor（Level 0，[N]）与 relic.scientific.isotopes.wire_isotope_tracker 在对模拟器或 StateManager 产生任何修改之前即以 runtime_unbound 拒绝执行。

  • 历史上在带外维护状态的 MultiIsotopePoolTracker 类已被删除（[X]），原因是在 StateManager 之外直接修改私有库字典违反了单一写入者溯源与守恒审计规则。

一般守恒输运 Functor

relic.scientific.transport 中的全部 3 个 Functor 均继承自 TransportMechanismFunctor，在有限体积上链复形上组装有向面通量，通过 UpdateItem(ACCUMULATE, per_timestep=True) 发出时间积分后的浓度增量，并在离散体积账本中显式核算边界通量与所配置的非负截断残差 \(R_{\mathrm{clip}}\)

\[ \sum_i V_i c_i^{n+1} - \sum_i V_i c_i^n = -\Delta t \sum_{f \in \partial\Omega} A_f q_f + \Delta t \sum_i V_i s_i + R_{\mathrm{clip}}. \]

有限体积迎风线性平流（LinearAdvection，Level 3）

relic.scientific.transport.advection.LinearAdvection（Level 3）采用有向迎风面通量离散平流方程 \(\partial_t c + \nabla \cdot (\mathbf{v} c) = s\)（LeVeque, 2002）：

\[\begin{split} \frac{\mathrm{d}c_i}{\mathrm{d}t} = -\frac{q_{i+1/2} - q_{i-1/2}}{\Delta x_i} + s_i, \qquad q_{i+1/2} = \begin{cases} v_{i+1/2}\,c_i, & v_{i+1/2} \ge 0,\\ v_{i+1/2}\,c_{i+1}, & v_{i+1/2} < 0, \end{cases} \end{split}\]

算子强制执行受 ParameterManager 管控的平流库朗-弗里德里希斯-列维（Courant-Friedrichs-Lewy, CFL）稳定性上限 \(\mathrm{CFL} = \max_i (\lvert v_i \rvert \Delta t / \Delta x_i) \le \mathrm{CFL}_{\max}\)，并严格区分周期边界、封闭零通量壁面、Dirichlet 边界、Neumann 边界与开放流入/流出边界契约。

菲克扩散：Level-3 一般算子与 Level-4 耗散端口哈密顿点

  1. 一般多维开放/有界模式（FickianDiffusion，Level 3）：relic.scientific.transport.diffusion.FickianDiffusion 在一维、二维与三维网格支撑上将扩散方程 \(\partial_t c = \nabla \cdot (\mathbf{K}\nabla c) + s\) 离散为上链形式 \(\dot{\mathbf{c}}_h = -D_h \mathbf{q}_{\mathrm{diff},h} + G_h \mathbf{u}_h\)，采用调和平均面扩散通量 \(\mathbf{q}_{\mathrm{diff},h} = -\star_K d_h \mathbf{c}_h\)（\(\star_K = \star_K^{\mathsf{T}} \succeq 0\)）并执行显式扩散稳定性审计 \(\mu = K \Delta t / \Delta x^2 \le \mu_{\max}\)（Crank, 1975）。

  2. 封闭一维无源耗散端口哈密顿运行时点（Level 4）：在构造条件次级证书 constructor_selection = {strict_runtime_point: True, spatial_dims: 1}（FickianDiffusion strict runtime point，Level 4）下，FickianDiffusion 将执行域限定于间距为 \(\Delta x\) 的封闭（周期或零通量壁面）一维均匀网格，令边界端口为零（\(G_h = 0\)），并以故障封闭方式拒绝一切非零 source_term。绑定二次 \(L^2\) 储能泛函与自动微分势余向量

    \[H_h(\mathbf{c}_h) = \frac{1}{2}\,\mathbf{c}_h^{\mathsf{T}}\mathbf{c}_h, \qquad \mathbf{e}_H = \frac{\partial H_h}{\partial \mathbf{c}_h} = \mathbf{c}_h,\]

    生产代码的有限体积扩散漂移项同规范耗散端口哈密顿（dPH）结构（\(J_h = 0\)）恒等重合：

    \[\frac{\mathrm{d}\mathbf{c}_h}{\mathrm{d}t} = (J_h - R_h)\,\mathbf{e}_H = -R_h\,\mathbf{c}_h, \qquad R_h = \frac{1}{\Delta x^2}\,d_h^{\mathsf{T}}\operatorname{diag}(K_f)\,d_h = R_h^{\mathsf{T}} \succeq 0,\]

    从而满足单调储能耗散

    \[\frac{\mathrm{d}H_h}{\mathrm{d}t} = -\mathbf{e}_H^{\mathsf{T}} R_h\,\mathbf{e}_H = -\sum_f K_f\left(\frac{\Delta_f c_h}{\Delta x}\right)^2 \le 0\]

    以及精确离散质量守恒 \(\mathbf{1}^{\mathsf{T}} R_h \mathbf{c}_h = 0\)。在该配置下的每一个输出时间步，forward() 均在 required_level = 4 等级上执行 relic.computation.operators.iphs.IPHSStructureSpec.validate，并将实时审计结果记录至 last_strict_iphs_audit（van der Schaft and Jeltsema, 2014）。由于等温示踪物扩散不声明热力学熵泛函 \(S_h\) 或可逆-不可逆 GENERIC 交叉退化条件，其证书等级终止于 Level 4（Level 5 专用于含熵耦合的 GENERIC 表述）。

平流-扩散耦合与算子分裂精度（AdvectionDiffusion，Level 3）

relic.scientific.transport.advection_diffusion.AdvectionDiffusion（Level 3）通过可配置的顺序分裂（"sequential" Lie-Trotter 分裂，\(\Phi_D^{\Delta t}\circ \Phi_A^{\Delta t}\)）或对称分裂（"symmetric" Strang 分裂，\(\Phi_D^{\Delta t/2}\circ \Phi_A^{\Delta t}\circ \Phi_D^{\Delta t/2}\)）组合平流与扩散上链子流（\(\mathbf{q} = \mathbf{v}c - \mathbf{K}\nabla c\)，网格佩克莱数诊断量 \(\mathrm{Pe} = \lvert \mathbf{v} \rvert \Delta x / K\)；Hundsdorfer and Verwer, 2003）：

  • 对称 Strang 组合消除了首阶贝克-坎贝尔-豪斯多夫（Baker-Campbell-Hausdorff, BCH）对易子误差项 \([A, D]\Delta t^2 / 2\)；在与 "implicit_midpoint" 等二阶子流积分器配合时，可实现 \(O(\Delta t^2)\) 阶的分裂对易误差。

  • 在默认的一阶显式 "euler" 子积分器下，单步局部截断误差为 \(O(\Delta t^2)\)，因此即便选用 "symmetric" 对称分裂，复合 AdvectionDiffusion 轨迹的全局精度仍为一阶 \(O(\Delta t)\)。

在空间网格上输运稳定同位素时，调用方应分别输运守恒的重同位素浓度与轻同位素浓度 \((c_h, c_l)\)，并在输运步完成后诊断重构 \(\delta\)，禁止对非守恒的 \(\delta\) 值直接施加平流或扩散算子。
