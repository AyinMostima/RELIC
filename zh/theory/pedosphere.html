土壤圈过程理论

范围、过程清单与证书映射

RELIC 土壤圈领域（relic.scientific.pedosphere）刻画凋落物与土壤有机碳周转、跨圈层凋落物与水文链映射、土壤氮矿化、硝化、反硝化与淋溶、根系氮磷吸收、诊断性碳氮（C:N）化学计量审计、湿地甲烷产生、氧化、三通道输运与单一归属收支实现，以及多孔介质水分、气体、溶质输运、Freundlich 指标-1 平衡吸附微分代数方程（Differential-Algebraic Equation, DAE）、移动域任意拉格朗日-欧拉（Arbitrary Lagrangian-Eulerian, ALE）扩散与流动-不动双区质量传递（《生态学分析方法》，第 23 章）。

土壤有机碳周转与跨圈层界面映射

五库观测与互斥分解闭合

在规范五库面积基准碳向量 \(\mathbf{C} = (C_{\mathrm{met}}, C_{\mathrm{str}}, C_{\mathrm{fast}}, C_{\mathrm{slow}}, C_{\mathrm{passive}})^{\mathsf{T}}\) [g C m\(^{-2}\)] 上，CarbonPoolsFunctor（Level 1）沿碳库维计算单网格总储量 \(C_{\mathrm{total}}(c) = \sum_i C_i(c)\)，不跨不等面积网格单元直接相加，也不修改碳储量（\(\Delta \mathbf{C} = \mathbf{0}\)）。

对于给定的土壤碳支撑域，同一仿真图至多选择一个预报分解归属算子（Parton et al., 1987；Coleman and Jenkinson, 1996；Wieder et al., 2013）：

  1. 分室矩阵（PoolsMatrix，Level 2）：设对角周转率矩阵为 \(K\) [s\(^{-1}\)]、列次随机转移矩阵为 \(T\)（\(T_{ij} \ge 0\)，\(\sum_i T_{ij} \le 1\)）、环境标量为 \(f_{\mathrm{env}}\)、凋落物输入向量为 \(\mathbf{I}\) [g C m\(^{-2}\) s\(^{-1}\)]，则

    \[\mathbf{D} = f_{\mathrm{env}} K \mathbf{C}, \qquad \frac{\mathrm{d}\mathbf{C}}{\mathrm{d}t} = (T - I_d)\mathbf{D} + \mathbf{I}, \qquad R_{\mathrm{hetero}} = \mathbf{1}^{\mathsf{T}}(I_d - T)\mathbf{D},\]

    严格满足开放碳收支账本 \(\sum_i \Delta C_i + R_{\mathrm{hetero}}\Delta t - \sum_i I_i\Delta t = 0\)。

  2. 分库一级动力学（FirstOrderDecomposition，Level 2）：在 \(Q_{10}\) 或 Arrhenius 温度标度及黏粒/木质素稳定化修正因子 \(f_{q,i}\) 下，以分库衰减速率 \(D_i = k_i\,f_T(T)\,f_\theta(\theta)\,f_{q,i}\,C_i\) 替代标量乘积 \(f_{\mathrm{env}}K\)，并闭合同一五库碳储量与 \(R_{\mathrm{hetero}}\) 账本。

  3. 逆米氏微生物-胞外酶动力学（MicrobialEnzymeDecomposition，Level 2）：在碳利用效率 \(\mathrm{CUE} \in (0, 1)\) 下，将底物碳库 \(S_i\) [g C m\(^{-2}\)] 与活性微生物生物量 \(M_{\mathrm{mic}}\) [g C m\(^{-2}\)] 相耦合：

    \[V_i = \frac{M_{\mathrm{mic}}\,V_{\max,i}(T, \theta)\,S_i}{K_{m,i}(T) + M_{\mathrm{mic}}}, \qquad \frac{\mathrm{d}M_{\mathrm{mic}}}{\mathrm{d}t} = \mathrm{CUE}\sum_i V_i - D_{\mathrm{mic}}, \qquad R_{\mathrm{microbial}} = (1 - \mathrm{CUE})\sum_i V_i + D_{\mathrm{mic}},\]

    其中 \(D_{\mathrm{mic}} = (\tau_{\mathrm{turn}} + \tau_{\mathrm{maint}}f_T)M_{\mathrm{mic}}\)，使得在计入外源凋落物输入之前满足 \(\sum_i \Delta S_i + \Delta M_{\mathrm{mic}} + R_{\mathrm{microbial}}\Delta t = 0\)。

凋落物与水文链映射

LitterfallInterfaceMapper（Level 2）将植物凋落物与牲畜粪便输入分配至代谢性与结构性凋落物端口，同时严格保持碳、氮总质量守恒：\(F_{\mathrm{met,C}} + F_{\mathrm{str,C}} = F_{\mathrm{plant,C}} + F_{\mathrm{dung,C}}\) 且 \(F_{\mathrm{org,N}} = F_{\mathrm{plant,N}} + F_{\mathrm{dung,N}}\)。PedosphereInterfaceMapper（Level 2）通过恒等链映射 \(\mathbf{y}_h = I_3\mathbf{x}_h\)（REPLACE）将水文边界通量（入渗、蒸散发、排水）投影至土壤圈端口名称，不重复计算水文闭合方程。

土壤氮循环、根系磷吸收与碳氮化学计量边界

矿化、硝化、反硝化、聚合与淋溶

  1. 矿化与固持（MineralizationProcess，Level 2）：在时间步 \(\Delta t\) 内以可用氮库储量约束有机氮总矿化速率与微生物 \(\mathrm{NH_4^+}\) 固持速率：

    \[R_{\mathrm{gross}} = \min\!\left(k_{\min} N_{\mathrm{org}} f_{\mathrm{env}},\; \frac{N_{\mathrm{org}}}{\Delta t}\right), \qquad R_{\mathrm{immob}} = \min\!\left(\frac{\mathrm{CUE}\cdot \mathrm{DEC}}{\mathrm{CN}_{\mathrm{mic}}\,\eta_N},\; \frac{N_{\mathrm{NH_4}}}{\Delta t}\right),\]

    在内部氮转化过程中保持 \(\Delta N_{\mathrm{org}} + \Delta N_{\mathrm{NH_4}} + \Delta N_{\mathrm{mic}} = 0\)。

  2. 硝化（NitrificationProcess，Level 2）与反硝化（DenitrificationProcess，Level 2）：二者均读取 water_filled_pore_space \(W \in [0, 1]\)（Linn and Doran, 1984；Del Grosso et al., 2000），并采用已归档的 RELIC 分段线性好氧与厌氧斜坡函数（\(W_{\mathrm{opt}} = W_{\mathrm{thr}} = 0.6\)，下界底值 \(0.1\)）：

    \[r_{\mathrm{nit}} = V_{\max,\mathrm{nit}}\,\frac{N_{\mathrm{NH_4}}}{K_{m,\mathrm{NH_4}} + N_{\mathrm{NH_4}}}\,f_T\,f_{\mathrm{pH}}\,f_{\mathrm{O_2}}(W), \qquad r_{\mathrm{denit}} = V_{\max,\mathrm{denit}}\,\frac{N_{\mathrm{NO_3}}}{K_{m,\mathrm{NO_3}} + N_{\mathrm{NO_3}}}\,f_{\mathrm{anaer}}(W)\,f_C\,f_T\,f_{\mathrm{pH}},\]

    分别闭合局地氮质量账本 \(\Delta N_{\mathrm{NH_4}} + \Delta N_{\mathrm{NO_3}} + \Delta N_{\mathrm{N_2O,nit}} = 0\) 与 \(\Delta N_{\mathrm{NO_3}} + \Delta N_{\mathrm{N_2O,denit}} + \Delta N_{\mathrm{N_2}} = 0\)。

  3. 诊断性氮聚合（NitrogenCycling，Level 2）与阻滞淋溶（NitrogenLeachingProcess，Level 3）：NitrogenCycling 仅对子过程速率做诊断性汇总，不重复运行子过程动力学，并仅通过 UpdateItem(ACCUMULATE, per_timestep=True) 提交外源施肥与尿液铵态氮增量 \(\Delta N_{\mathrm{NH_4,ext}} = 1000(F_{\mathrm{fert}} + F_{\mathrm{urine}})\Delta t\)。NitrogenLeachingProcess 由流动相阻滞硝态氮浓度 \(C_{\mathrm{NO_3,mob}} = \frac{N_{\mathrm{NO_3}}/(\theta z_s)}{1 + \rho_b K_d / \theta}\) 与水分排水通量 \(F_w\) 计算排水驱动的淋溶输出，并受可用氮库与最小耗竭时间尺度约束，从而满足 \(\Delta N_{\mathrm{NO_3}} + F_{N,\mathrm{leach}}\Delta t = 0\)。

根系氮磷吸收与 C:N 诊断范围

relic.scientific.pedosphere.nutrient_cycling.root_nutrient_uptake.RootNutrientUptake（Level 2）依据分层米氏动力学 \(U_i(z) = V_{\max,i}\frac{C_i(z)}{K_{m,i} + C_i(z)} f_T f_W W_{\mathrm{root}}(z)\)（Barber, 1995）计算根系对 \(\mathrm{NO_3^-}\)、\(\mathrm{NH_4^+}\) 及溶解态磷的吸收。摩尔基准植物氮库 \(S_N\) [mol N m\(^{-2}\)] 与质量基准土壤无机氮库 \(m_{\mathrm{NO_3}}, m_{\mathrm{NH_4}}\) [g N m\(^{-2}\)] 通过 \((\Delta m_{\mathrm{NO_3}} + \Delta m_{\mathrm{NH_4}})/M_N + \Delta S_N = 0\) 闭合。实际实现的摩尔磷吸收速率 \(U_P\) [mol P m\(^{-2}\) s\(^{-1}\)] 由动力学吸收能力 \(U_{P,\mathrm{kin}}\)、植物磷需求 \(D_P\)、土壤有效活性磷 \(P_{\mathrm{avail}}\) [g P m\(^{-2}\)] 以及植物剩余储磷容量 \(P_{\mathrm{cap,mol}}\) [mol P m\(^{-2}\)] 的四重极小值定界：

\[ U_P = \min\!\left(U_{P,\mathrm{kin}},\; D_P,\; \frac{P_{\mathrm{avail}}}{M_P\,\Delta t},\; \frac{P_{\mathrm{cap,mol}}}{\Delta t}\right), \qquad \Delta P_{\mathrm{avail}} + \Delta P_{\mathrm{plant}} = 0. \]

磷循环与化学计量范围边界：RootNutrientUptake（配合 FertilizationManagement 的管理施磷输入以及 NutrientStress 的叶片 N:P 限制标量）共同构成已实现 [I] 的磷接口；独立的多库土壤磷风化、闭蓄态转化、有机磷矿化及磷淋溶算子当前保持 [N] 状态。此外，relic.scientific.pedosphere.nutrient_cycling.stoichiometry.StoichiometryConstraint（Level 1，ScaleCouplingFunctor）属于只读 C:N 通量比与质量平衡诊断观测算子（\(\Delta \mathbf{x} = \mathbf{0}\)），既不将状态投影至化学计量流形，也不审计磷库。

湿地甲烷请求-耦合器架构

为避免产甲烷、甲烷氧化与三通道气体逸出之间出现相互竞争的库存截断，RELIC 将湿地 \(\mathrm{CH_4}\) 拆分为三个无状态倾向/请求算子、一个预报收支归属算子以及一个诊断性尺度路由观测算子：

  1. 产生请求（MethaneProductionFunctor，Level 2）：以门控权重 \(w \in [0, 1]\) 与带峰值的温度响应函数 \(f_{ST}(T)\)（Zhu et al., 2014）加权融合 iMAPLE 淹水分支（Yue et al., 2024, Eq. 34）与氧化还原门控率定分支：

    \[P_{\mathrm{CH_4}} = (1 - w)\,R_h r f_{ST}(T) f_{\mathrm{pH}} f_{\mathrm{wet}} + w\,R_h r f_{ST}(T) f_{Eh}(Eh)\,A.\]

  2. 氧化请求（MethaneOxidationFunctor，Level 2）：基于孔隙水 \(\mathrm{CH_4}\) 与 \(\mathrm{O_2}\) 浓度计算双底物米氏动力学（Riley et al., 2011, Eq. 7；Oleson et al., 2013, Eq. 19.11），并以 \(M_{\mathrm{CH_4}}/\Delta t\) 为上界。

  3. 三通道输运请求（MethaneTransportFunctor，Level 3）：将液-气分子扩散 \(F_{\mathrm{diff}}\)、阈值气泡逸出 \(F_{\mathrm{ebull}}\) 与通气组织植物介导排放 \(F_{\mathrm{plant}}\)（Walter and Heimann, 2000）求和为 \(F_{\mathrm{req}} = F_{\mathrm{diff}} + F_{\mathrm{ebull}} + F_{\mathrm{plant}}\) 及 \(T_{\mathrm{trans}} = -F_{\mathrm{req}}\)（REPLACE）。

  4. 唯一收支实现算子（MethaneBudgetCoupler，Level 2）：积分合成总倾向 \(\Delta M_{\mathrm{raw}} = (T_{\mathrm{prod}} + T_{\mathrm{oxid}} + T_{\mathrm{trans}})\Delta t\)，通过 \(\Delta M = \max(\Delta M_{\mathrm{raw}}, -M_{\mathrm{CH_4}})\) 一次性施加非负约束，将 \(\Delta M\) 提交至 ch4_soil_storage（ACCUMULATE，per_timestep=True），并从实际大气排放通量中扣除库存限制亏缺 \(R_{\mathrm{lim}} = (\Delta M - \Delta M_{\mathrm{raw}})/\Delta t\)，即 \(F_{\mathrm{atm}} = F_{\mathrm{req}} - R_{\mathrm{lim}}\)，从而严格满足 \(\Delta M + (O - P_{\mathrm{CH_4}} + F_{\mathrm{atm}})\Delta t = 0\)。MethaneScaleCouplingFunctor（Level 1）计算有界诊断路由权重 \(w_{\mathrm{DNDC}} = \operatorname{clip}(\alpha_{\mathrm{wet}}f_{\mathrm{wet}} + \alpha_{\mathrm{wfps}}W + \alpha_{\mathrm{data}}s_{\mathrm{data}} - \tau,\; 0,\; 1)\)。

多孔介质水分、气体、溶质、DAE、ALE 与记忆核输运

Richards 水分运动、Millington-Quirk 气体扩散与阻滞溶质输运

  • SoilWaterTransportFunctor（Level 3）以离散上链形式 \(\dot{\boldsymbol{\theta}}_h = -D_h \mathbf{q}_h + G_h \mathbf{u}_h\)（\(\star_K = \star_K^{\mathsf{T}} \succeq 0\)）求解一维混合形式 Richards 方程 \(\partial_t \theta = -\partial_z q + S\)（其中 \(q = -K(\theta)\partial_z(h + z)\)），并通过 REPLACE 输出完整下一时刻 soil_moisture。

  • GasDiffusion1D（Level 3）在零通量下边界之上，依据 Millington and Quirk (1961) 弯曲度系数计算包气带 \(\mathrm{CO_2}\)-C 与 \(\mathrm{N_2O}\)-N 剖面扩散（浓度增量采用 ACCUMULATE，地表逸出通量采用 REPLACE）。

  • SoluteAdvectionDiffusion1D（Level 3）针对 \(\mathrm{NO_3^-}\)-N 与 DOC-C 求解一维阻滞平流-弥散方程 \(\partial_t\left((\theta + \rho_b K_d)C\right) = -\partial_z\left(q C - K_{\mathrm{disp}}\partial_z C\right)\)，并校验质量平衡 \(M^{n+1} - M^n - (F_{\mathrm{top}} - F_{\mathrm{bot}})\Delta t = 0\)。

Freundlich 平衡吸附指标-1 描述符 DAE（EquilibriumSorptionFunctor，Level 2）

relic.scientific.pedosphere.transport.equilibrium_sorption.EquilibriumSorptionFunctor（Level 2，PhysicalFieldFunctor）将非线性 Freundlich 平衡吸附 \(S = K_f C^n\)（\(n \in [0.3, 1.0]\)）与溶解相一级降解速率 \(\lambda \ge 0\)（Jury and Horton, 2004；Mayes et al., 2012；Hairer and Wanner, 1996）表述为状态向量 \(\mathbf{x} = (y, C, S)^{\mathsf{T}}\) 与描述符矩阵 \(E = \operatorname{diag}(1, 0, 0)\) 上的半显式指标-1 描述符 DAE：\(E\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x})\)，\(\mathbf{g}(\mathbf{x}) = \mathbf{0}\)：

\[ \frac{\mathrm{d}y}{\mathrm{d}t} = -\lambda\,\theta\,C, \qquad g_1(y, C, S) = \theta C + \rho_b S - y = 0, \qquad g_2(C, S) = S - K_f C^n = 0. \]

由于当 \(\theta > 0\) 且 \(C > 0\) 时 \(\partial_C(\theta C + \rho_b K_f C^n - y) = \theta + \rho_b K_f n C^{n-1} > 0\)，代数雅可比恒为严格正值（微分指标为 1）。在每一时间步（含检查点重启后对已存储三元组 \((y, C, S)\) 的一致性校验），隐式向后欧拉消元求解如下严格单调标量方程

\[ F(C') = \theta(1 + \lambda\,\Delta t)C' + \rho_b K_f (C')^n - y = 0, \qquad C' \in \left[0,\; \frac{y}{\theta}\right], \]

该方程由 relic.computation.solvers.nonlinear.BracketedBisectionSolver 求解，随后通过 UpdateItem(ACCUMULATE, per_timestep=True) 更新微分总质量 \(y' = y - \lambda\,\theta\,C'\Delta t\)，通过 REPLACE 替换代数状态 \(C'\) 与 \(S' = K_f (C')^n\)，并输出步后流形残差 \(\lvert \theta C' + \rho_b S' - y' \rvert\)。

一维 ALE 移动域扩散与精确 GCL（MovingDomainDiffusionFunctor，Level 3）

relic.scientific.pedosphere.transport.moving_domain_diffusion.MovingDomainDiffusionFunctor（Level 3，TransportMechanismFunctor）在下边界速度 \(w_b\) [m s\(^{-1}\)] 驱动的均匀拉伸或压缩一维土柱 \(x(\xi, t) = \xi L(t)\)（\(\xi \in [0, 1]\)）上求解 Fick 溶质扩散（Thomas and Lombard, 1979；Donea et al., 2004）。设共有 \(N\) 个均匀网格单元，单元厚度为 \(V_i(t) = \Delta x(t) = L(t)/N\)，界面速度为 \(w_k = (k/N)w_b\)（\(k = 0, \dots, N\)），离散几何守恒律（GCL）恒等成立：

\[ V_i(t + \Delta t) - V_i(t) = \Delta t\,(w_{i+1} - w_i) = \frac{w_b\,\Delta t}{N}, \qquad L(t + \Delta t) = L(t) + w_b\,\Delta t. \]

在同时满足扩散冯·诺依曼稳定性判据与网格 Courant 条件（\(\lvert w_b \rvert \Delta t / \Delta x \le \mathrm{CFL}_{\mathrm{mesh,max}}\)）下，单元溶质质量 \(m_i = V_i c_i\) 由零通量边界内部扩散与迎风相对扫掠界面通量 \(s_k = c_{\mathrm{face},k} w_k\) 共同推进（当 \(w_b > 0\) 时卷吸外部浓度 \(c_b\)，当 \(w_b < 0\) 时输出底层单元浓度 \(c_{N-1}\)）：

\[ m_i(t + \Delta t) = m_i(t) + \Delta t\left(r_{\mathrm{diff},i}\,\Delta x(t) + s_{i+1} - s_i\right), \qquad c_i(t + \Delta t) = \frac{m_i(t + \Delta t)}{V_i(t + \Delta t)}. \]

在含时 Hodge 度量 \(\star(t) = \operatorname{diag}(L(t)/N)\)、二次储能泛函 \(H = \frac{1}{2}\mathbf{c}^{\mathsf{T}}\star(t)\mathbf{c}\) 与 \(\dot{\star} = \operatorname{diag}(w_b / N)\) 下，移动几何功率项 \(-\frac{1}{2}\mathbf{c}^{\mathsf{T}}\dot{\star}\mathbf{c}\) 与 gcl_residual、mass_balance_residual 一并显式输出于 diagnostics.moving_domain.geometry_power。

流动-不动双区精确指数记忆核交换（TwoRegionMassTransferFunctor，Level 3）

relic.scientific.pedosphere.transport.two_region_mass_transfer.TwoRegionMassTransferFunctor（Level 3，TransportMechanismFunctor）实现了流动孔隙水区（\(\theta_m, c_m\)）与滞留不动孔隙水区（\(\theta_{\mathrm{im}}, c_{\mathrm{im}}\)）之间速率系数为 \(\alpha > 0\) [s\(^{-1}\)] 的一级质量交换（van Genuchten and Wierenga, 1976；Haggerty and Gorelick, 1995）。在 \(\theta\) 加权储量状态 \(\mathbf{x} = (\theta_m c_m, \theta_{\mathrm{im}} c_{\mathrm{im}})^{\mathsf{T}}\)、二次自由能代理泛函 \(H(\mathbf{x}) = \frac{1}{2}(\theta_m c_m^2 + \theta_{\mathrm{im}} c_{\mathrm{im}}^2)\) 与共轭势变量 \(\mathbf{e} = \frac{\partial H}{\partial \mathbf{x}} = (c_m, c_{\mathrm{im}})^{\mathsf{T}}\) 下，该动力学构成纯耗散系统（\(J_h = 0\)）：

\[\begin{split} \frac{\mathrm{d}\mathbf{x}}{\mathrm{d}t} = -R_h\mathbf{e}, \qquad R_h = \alpha \begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix} \succeq 0, \qquad \frac{\mathrm{d}H}{\mathrm{d}t} = -\alpha(c_m - c_{\mathrm{im}})^2 \le 0. \end{split}\]

消去 \(c_{\mathrm{im}}\) 可得无源指数 Volterra 记忆核 \(K(t) = \alpha\omega\exp(-\omega t)\)（其中 \(\omega = \alpha / \theta_{\mathrm{im}}\)）。在每一时间步 \(\Delta t\) 内，TwoRegionMassTransferFunctor 通过精确矩阵指数 \(c_m(t+\Delta t) - c_{\mathrm{im}}(t+\Delta t) = (c_m(t) - c_{\mathrm{im}}(t))\exp(-\kappa \Delta t)\)（其中 \(\kappa = \alpha(\theta_m^{-1} + \theta_{\mathrm{im}}^{-1})\)）解析推进该 \(2 \times 2\) 线性交换系统，在机器精度上守恒孔隙总溶质 \(\theta_m \Delta c_m + \theta_{\mathrm{im}}\Delta c_{\mathrm{im}} = 0\)，并在状态更新记录中声明 relic.core.functor.SubFlowAccuracy.EXACT。
