校准、敏感性分析和不确定性量化

RELIC 基于权威参数系统，以 Python API 形式提供参数校准、由 Python 灵敏度分析库（Sensitivity Analysis Library in Python, SALib）支撑的全局灵敏度分析、不确定性量化（Uncertainty Quantification, UQ）以及数据同化组件。每个模型回调函数均接收一份参数映射，由回调负责运行目标 RELIC 模型并返回约定形状的输出结果。

可用性

from relic.optimization import get_available_optimizers

status = get_available_optimizers()
print(status)

返回的映射报告了校准、同化、敏感性和不确定性家族的导入可用性。导入可用性并不保证模型回调、观测映射、参数范围或可选数值后端有效。

参数校准

可学习参数由 ParameterManager 管理。通过 manager.get_trainable_parameters() 获取实时 nn.Parameter 对象，用于管理器校准路径。Functor 按引用持有自身管理器的绑定，因此模块的 parameters() 和 state_dict() 不包含它。parameter_sensitivity(parameter_name, state, *, time, dt, ...) 通过函数式替换模块成员计算，对管理器绑定抛出 TypeError。形状和 dtype 不变时，重新注册会原地更新值，保留 Functor 与优化器持有的引用。

ParameterBounds

ParameterBounds(
    lower: float,
    upper: float,
    scale: str,
    initial: Optional[float] = None,
)

lower 必须小于 upper。显式 initial 必须在区间内。scale 必填，取 linear 或 log；其他值抛出 ValueError。

CalibrationConfig

CalibrationConfig(
    method: CalibrationMethod,
    target_parameters: list[str],
    parameter_bounds: dict[str, ParameterBounds],
    max_iterations: int = ...,
    tolerance: float = ...,
    population_size: Optional[int] = None,
    random_seed: Optional[int] = None,
    parallel: bool = False,
    n_workers: Optional[int] = None,
    method_kwargs: dict[str, Any] = {},

    verbose: bool = True,
)

参数

含义

method

优化算法

target_parameters

完全限定的参数键用于校准

parameter_bounds

每个目标参数由Bounds键控。

max_iterations

优化器最大迭代数或代数；未设置时读取 optimization.calibration.max_iterations。

tolerance

收敛容差；未设置时读取 optimization.calibration.objective_tolerance。

population_size

基于人口的方法的人口规模。

random_seed

NumPy和PyTorch采样的可重复性种子。

parallel， n_workers

并行评估请求和工作限速。

method_kwargs

算法特定选项。

cross_validation_folds

Optional折叠次数

save_progress， progress_file

持久性进展控制。

verbose

优化器日志控制

受支持的 CalibrationMethod 枚举值包括差分进化、遗传算法、模拟退火、粒子群优化、贝叶斯优化、梯度下降、Adam 以及有限内存拟牛顿法（Limited-memory Broyden-Fletcher-Goldfarb-Shanno, L-BFGS）。

该 enum 是共享的方法标识，而不是一个囊括八种算法的执行 facade。ParameterCalibrator 仅拥有五种无导数方法：differential evolution、genetic algorithm、simulated annealing、particle swarm 和 Bayesian optimization。GradientCalibrator 单独拥有 gradient descent、Adam 和 L-BFGS。将梯度方法传给 ParameterCalibrator.calibrate(...) 会在日志、hook、RNG、ParameterManager 修改、目标函数求值、分派或进度效果发生之前抛出异常。

ParameterCalibrator（无导数方法 owner）

ParameterCalibrator(
    parameter_manager: Optional[UnifiedParameterManager] = None,
    hooks: Optional[CalibrationHooks] = None,
)

calibrator.calibrate(
    config: CalibrationConfig,
    objective_function: ObjectiveFunction,
    observations: torch.Tensor,
    initial_parameters: Optional[dict[str, float]] = None,
) -> CalibrationResult

ObjectiveFunction.__call__(parameters, observations) 返回待最小化的标量目标值。内置目标函数类包括均方误差（Mean Squared Error, MSEObjective）、均方根误差（Root Mean Squared Error, RMSEObjective）以及纳什-萨特克利夫效率系数目标 NashSutcliffeObjective。

import torch

from relic.parameters.calibration import (
    CalibrationConfig,
    CalibrationMethod,
    MSEObjective,
    ParameterBounds,
    ParameterCalibrator,
)


def model_runner(parameters):
    rate = parameters["model.rate"]
    return torch.tensor([rate, 2.0 * rate], dtype=torch.float32)


config = CalibrationConfig(
    method=CalibrationMethod.DIFFERENTIAL_EVOLUTION,
    target_parameters=["model.rate"],
    parameter_bounds={
        "model.rate": ParameterBounds(
            lower=0.1,
            upper=2.0,
            scale="linear",
            initial=0.5,
        )
    },
    max_iterations=50,
    random_seed=42,
    parallel=False,
    save_progress=False,
)
objective = MSEObjective(model_runner, variable_names=[])
observations = torch.tensor([1.0, 2.0], dtype=torch.float32)

calibrator = ParameterCalibrator()
result = calibrator.calibrate(
    config,
    objective,
    observations,
    initial_parameters={"model.rate": 0.5},
)
print(result.success, result.optimized_parameters)

目标键必须对活动参数管理器有效，回调返回值必须与观测张量兼容。模型失败或内置标量目标缺少输出变量时会报错，不返回无穷惩罚值。校准失败会触发 CALIBRATION_ERROR 钩子事件并重新抛出异常。

GradientCalibrator(
    parameter_manager: UnifiedParameterManager,
    config: Optional[GradientCalibrationConfig] = None,
    hooks: Optional[CalibrationHooks] = None,
)

gradient_calibrator.calibrate(
    objective_function,
    observations,
    target_parameters: Optional[list[str]] = None,
    parameter_bounds: Optional[dict[str, tuple[float, float]]] = None,
) -> CalibrationResult

method 必填。未设置的数值选项（显示为 ...）从参数数据库的 optimization.calibration.* 读取，其中 Adam 设置采用 Kingma 和 Ba（2015）算法 1 的值。GradientCalibrator 同时要求调用方的 ParameterManager 和 config；缺少任一项均抛出 ValueError，因此不允许隐式进程全局校准状态或默认优化器。目标必须返回单个有限、可微的标量，每个请求的目标参数必须产生有限梯度。在将一个接受点作为原子管理器批次提交前，候选值始终与规范管理器状态隔离。

import torch

from relic.parameters import get_global_manager
from relic.parameters.calibration import (
    CalibrationMethod,
    GradientCalibrationConfig,
    GradientCalibrator,
)

manager = get_global_manager()
snapshot = manager.snapshot()
target_key = "stochastic.weather.temperature.reversion_rate"
try:
    grad_config = GradientCalibrationConfig(
        method=CalibrationMethod.ADAM,
        learning_rate=0.05,
        max_iterations=80,
        tolerance=1e-4,
        verbose=False,
        save_progress=False,
    )
    grad_calibrator = GradientCalibrator(manager, config=grad_config)
    observations = torch.tensor([0.2, 0.4], dtype=torch.float64)

    def differentiable_objective(params, obs):
        alpha = params[target_key]
        prediction = torch.stack([alpha, 2.0 * alpha])
        return torch.mean((prediction - obs) ** 2)

    grad_result = grad_calibrator.calibrate(
        differentiable_objective,
        observations,
        target_parameters=[target_key],
        parameter_bounds={target_key: (0.01, 1.0)},
    )
    print(round(grad_result.optimized_parameters[target_key], 2))
finally:
    manager.restore(snapshot)

全球敏感性分析

ParameterRange

ParameterRange(
    name: str,
    lower_bound: float,
    upper_bound: float,
    mean: Optional[float] = None,
    std: Optional[float] = None,
    integer_valued: bool = False,
    log_scale: bool = False,
    units: str = "",
    description: str = "",
    *,
    distribution: str,
)

distribution 是必填的仅关键字参数，取 uniform、normal、lognormal 或 triangular。上下界必须有序。normal 和 lognormal 需要显式 mean 和有限正值 std（lognormal 的 mean 为正中位数）；triangular 需要用边界内的 mean 指定众数，不从边界推导这些值。sample(n_samples, random_state=None) 使用局部生成器抽样，将正态和对数正态样本裁剪到边界，并按请求应用整数或对数变换。声明的 units 必须等于同名参数键 ParameterSpec 的单位；分析器验证范围时，为非参数名称声明单位会抛出 ValueError。Morris 和 Sobol 仅接受不带对数缩放或整数值的均匀范围；其他声明抛出 NotImplementedError。

回调契约

两者分析器使用：

analyze(
    model_runner: Callable[
        [dict[str, float]],
        dict[str, float],
    ],
    parameter_ranges: dict[str, ParameterRange],
    baseline_parameters: Optional[dict[str, float]] = None,
) -> SensitivityResult

跑者接受一个参数映射并以名称返回标量输出。baseline_parameters提供固定参数并与每个采样映射合并。

MorrisAnalyzer

MorrisAnalyzer(
    parameter_manager: UnifiedParameterManager,
    config: Optional[MorrisConfig] = None,
)

config 必填，未提供时构造分析器会抛出 TypeError。MorrisConfig 要求关键字 aggregation_method（mean、sum、max、std 或 final）；其数值字段 n_trajectories、n_levels 和 grid_jump 未设置时读取 optimization.sensitivity.morris.*。构造器要求轨迹数和网格跳跃量为正、至少两个水平，并满足 2 x grid_jump <= n_levels。

使用Morris筛选法按较少的评估次数排名许多参数。结果包含基本效应统计、输出级敏感性指数、执行次数、时间以及收敛metadata。

SobolAnalyzer

SobolAnalyzer(
    parameter_manager: UnifiedParameterManager,
    config: Optional[SobolConfig] = None,
)

此处 config 也必填（缺少时抛出 TypeError）。SobolConfig 要求关键字 aggregation_method 和 estimator；仅实现 saltelli 估计器（janon、glen 和 owen 均抛出 NotImplementedError）。其余字段为 n_samples、skip_values、scramble、calc_second_order、convergence_check、convergence_samples 和 batch_size；n_samples 与 skip_values 未设置时读取 optimization.sensitivity.sobol.*。样本数和批次数必须为正。

使用 Sobol 分析计算一阶和总阶方差分解；尚未实现二阶指数（calc_second_order=True 抛出 NotImplementedError）。参数范围映射为空时抛出 ValueError；分析失败包装为 RuntimeError。

from relic.optimization.sensitivity import (
    MorrisAnalyzer,
    MorrisConfig,
    ParameterRange,
)
from relic.parameters import get_global_manager

ranges = {
    "rate": ParameterRange(
        name="rate",
        lower_bound=0.1,
        upper_bound=2.0,
        distribution="uniform",
    )
}


def runner(parameters):
    return {"response": parameters["rate"] ** 2}


analyzer = MorrisAnalyzer(
    get_global_manager(),
    MorrisConfig(n_trajectories=10, n_levels=4, random_seed=42, aggregation_method="mean"),
)
sensitivity = analyzer.analyze(runner, ranges)
print(sensitivity.method, sensitivity.n_model_evaluations)

    description: str = "",
)

支持均匀、正态、对数正态、beta、gamma 和三角分布。上下界必须有序。NORMAL 和 LOGNORMAL 参数必须给出 mean 与 std；UNIFORM 参数缺少这两项时使用由边界确定的矩，三角分布参数需要显式 mode。alpha、beta 和 mode 配置各分布的形状。sample() 应用物理边界以及请求的整数或对数变换。

EnsembleUQ和BootstrapUQ

EnsembleUQ(
    parameter_manager: UnifiedParameterManager,
    config: Optional[EnsembleConfig] = None,
)

BootstrapUQ(
    parameter_manager: UnifiedParameterManager,
    config: Optional[BootstrapConfig] = None,
)

config 为必传参数：任一类在未传入该参数时构造均会抛出 TypeError。EnsembleConfig 要求以关键字参数传入 sampling_strategy（可选 random、拉丁超立方抽样（Latin Hypercube Sampling）lhs 或 sobol）；BootstrapConfig 要求以关键字参数传入 bootstrap_type（parametric 或 residual）与 ci_method（percentile 或 bca）。

均暴露：

quantify(
    model_runner: Callable[
        [dict[str, float]],
        dict[str, float],
    ],
    uncertain_parameters: dict[str, UncertainParameter],
    baseline_parameters: Optional[dict[str, float]] = None,
    observations: Optional[dict[str, numpy.ndarray]] = None,
) -> UQResult

EnsembleUQ通过回调传播采样参数分布。其配置控制ensemble大小、采样、并行评估、局部化、自适应采样、分块和异常值处理。BootstrapUQ支持参数和残差重采样；残差自助法使用observations。

UQResult报告输出均值、标准差、方差、百分位数、置信区间、可选样本、偏度、峰度、相关性、样本和评估计数、时间、收敛性、有效样本大小以及蒙特卡罗误差。

默认情况下，失败样本和缺失输出不予接受。仅当下游处理过程中明确处理结果 sentinel 值时才修改allow_failed_samples或allow_missing_outputs。

from relic.optimization.uncertainty import (
    DistributionType,
    EnsembleConfig,
    EnsembleUQ,
    UncertainParameter,
)
from relic.parameters import get_global_manager

uq = EnsembleUQ(
    get_global_manager(),
    EnsembleConfig(
        ensemble_size=16,
        sampling_strategy="lhs",
        random_seed=42,
        parallel_evaluation=False,
    ),
)
uq_result = uq.quantify(
    lambda p: {"flux": 2.0 * p["alpha"]},
    {
        "alpha": UncertainParameter(
            name="alpha",
            distribution=DistributionType.UNIFORM,
            lower_bound=0.1,
            upper_bound=0.5,
        )
    },
)
print(round(uq_result.output_mean["flux"], 2), uq_result.n_model_evaluations)
