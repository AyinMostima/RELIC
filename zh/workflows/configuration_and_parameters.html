配置与参数

RELIC 将结构化配置与科学参数值分离。RELICConfig 基于 relic.core.config.models 中的 15 个 Pydantic V2 BaseModel 类校验子系统结构（包括基类 ConfigurationModel、架构版本 2.0.0 的根模型 RELICConfig、10 个子系统配置模型，以及 DataConfig 下属的 3 个嵌套子模型 DataIOConfig、DataQualityConfig 与 DataTransformConfig，即 RELICConfig 下辖共计 13 个子系统及嵌套模型）；UnifiedParameterManager 则作为版本化科学参数值与元数据的单点事实源（Single Source of Truth, SSOT）。RELICSimulator 接收运行时映射，不直接消费 RELICConfig 对象。

ConfigLoader和load_config

from relic.core.config import ConfigLoader, load_config

loader = ConfigLoader()
config = loader.load_config(
    config_path=r"configs\simulation_minimal.yaml",
    overrides={"simulation.time_step": 1800.0},
    env_overrides=True,
)

config_unvalidated = load_config(
    r"configs\simulation_minimal.yaml",
    validate=False,
)

ConfigLoader.load_config(config_path=None, overrides=None, env_overrides=True) 是唯一配置加载路径。该方法以 UTF-8 编码读取配置文件，应用点分路径覆盖项，在 env_overrides 为真时应用环境变量覆盖，构建 RELICConfig，将 parameters.parameter_overrides 写入参数管理器（ParameterManager）并执行边界校验，随后运行 ConfigValidator。overrides 可为映射（如 {"simulation.time_step": 1800.0}）或 "dotted.key=value" 字符串列表；列表元素缺少 = 时直接抛出异常。环境变量仅在名称满足“RELIC_ 前缀加 RELICConfig 字段路径大写并以 "_" 连接”时才会被读取，例如 simulation.time_step 对应 RELIC_SIMULATION_TIME_STEP；其余 RELIC_* 变量不属于配置项。模块级函数 load_config(config_path=None, overrides=None, validate=True) 内部调用 ConfigLoader(validate_on_load=validate)；仅传入 validate=False 可跳过 ConfigValidator。ConfigValidator 支持在 YAML 中以字符串形式指定枚举字段，例如 integration_method: "euler"。

指定的配置（优先采用 config_path 参数，否则采用 RELIC_CONFIG_PATH）不存在时，抛出 FileNotFoundError。没有指定配置时，读取 relic.core.config.loader.DEFAULT_CONFIG_PATHS 中第一个存在的文件；都不存在时，使用全局默认配置（RELICConfig 的默认值，应用显式覆盖和环境覆盖）并记录该选择；relic.core.config.resolve_config_source 是 ConfigLoader、get_global_config 和 load_runtime_config 共用的唯一规则。其他所有加载失败都抛出 relic.core.config.loader.ConfigurationError，存在原始异常时将其设为 __cause__：包括不支持的后缀、无效 YAML、模型验证错误、格式错误的覆盖、不是已注册参数的 parameter_overrides 键，以及 ConfigValidator 错误。

Runtime配置映射

RELICSimulator 读取一个Python映射，使用.get()。不要直接传递RELICConfig实例。将类型化的设置映射到runtime键名：

from relic.core.config import RELICConfig
from relic.core.simulator import RELICSimulator

typed = RELICConfig.from_yaml(r"configs\simulation_minimal.yaml")
runtime_config = {
    "time_step": typed.simulation.time_step,
    "max_time": typed.simulation.end_time,
    "output_frequency": 1,  # simulator steps between time_series records
    "enable_checkpointing": False,
    "time_integration_method": typed.simulation.integration_method,
    "device": "auto",
}
simulator = RELICSimulator(runtime_config)

运行时键可置于映射根部，或置于 simulator、runtime、computation 节下。RELICSimulator 优先从根部读取各键，未命中时按上述顺序从首个包含该键的分节读取；device 与 require_gpu 遵循同一查找顺序。device_overrides 与 module_device_overrides 映射按根部、simulator、runtime、computation 的顺序合并，同名项以后出现者为准。SimulationConfig 不含 output_frequency 或检查点字段，此类运行时键需显式传入；该模型同样未声明自适应步长字段，自适应步进由运行时键 adaptive_dt_enabled、adaptive_atol、adaptive_rtol、adaptive_dt_min 与 adaptive_dt_max 配置，默认值取自 computation.scheduling.adaptive.* 参数。end_time 默认为 1 天，time_step 不得超过 1 小时（对应 relic.utils.time_constants 中的 SECONDS_PER_DAY 与 SECONDS_PER_HOUR）。模拟器不会将 simulation.end_time 这类类型化字段重命名为 max_time，也不会将 simulation.integration_method 重命名为 time_integration_method。

主要runtimekeys

key

含义

time_step

Functors参数传递给默认的步长持续时间。

max_time

run()使用默认结束时间，当未提供显式结束时间时。

output_frequency

time_series 中两次 Functor 输出值记录之间的模拟器步数（正整数，默认 1）。

enable_checkpointing

选择启用自动检查点写入；默认为 False。

checkpoint_directory

显式的自动检查点目录；启用检查点时必需。

checkpoint_frequency

自动检查点之间的模拟时间间隔，单位为秒（默认 3600.0）；启用检查点时必须为正。

time_integration_method

输运时间积分方法：euler、implicit_midpoint 或 crank_nicolson，对应 transport.numerical.time_integration_method 允许的值；该键未设置时使用此参数的值。其他值会在构造时引发 ValueError。此设置传给 forward() 声明了 time_integration_method 的 Functor。

implicit_midpoint_max_iter, implicit_midpoint_tolerance

隐式输运步的迭代上限和收敛容差；未设置时使用 transport.numerical.implicit_midpoint_max_iter 和 transport.numerical.implicit_midpoint_tolerance，显式配置值按其边界验证。

splitting_mode

执行循环使用的分裂求解模式。

strict_dependencies

在支持的情况下，升级依赖关系和普通输出重叠冲突。

conservation_checks

True 或 False 在运行时提交路径中启用守恒核算；映射只能设置 StateManager 的 enabled、raise_on_violation、rollback_on_failure（各为 True 或 False）以及 tolerance。其他类型、未知键或无效值会抛出 ValueError，并指出键和值。

conservation_raise_on_violation, conservation_rollback_on_failure

设置该映射的 raise_on_violation 和 rollback_on_failure。仅接受 True 或 False；"false" 这样的字符串或整数 0/1 会引发 ValueError；若值与 conservation_checks 中的同名键冲突，也会报错。

conservation_tolerance

显式覆盖 StateManager 提交时账本容差，其默认值为 validation.conservation.conservation_tolerance。必须是位于该参数声明边界内的有限实数（当前为 [1e-10, 1e-3]）；其他值会引发 ValueError，并指出键和值。

strict_conservation_enabled

升级配置的保护失败。

adaptive_dt_enabled

启用自适应时间步长控制。

adaptive_atol， adaptive_rtol

绝对和相对适应性误差容限。

adaptive_dt_min， adaptive_dt_max

Bounds 用于自适应时间步长。

adaptive_monitor_vars

用于自适应误差控制的状态变量。

device

全球设备策略：auto、cpu、cuda 或 cuda:N。

require_gpu

拒绝在true时使用CPU的后备方案。

device_overrides

设备按Functor名称请求。

module_device_overrides

设备按模块名称请求键。

state_units

初始状态变量的单位，以变量名到单位的映射提供；initialize_state() 构建 StateManager 时读取。单位与变量契约或目录声明不一致时，抛出 ValueError。

enable_distributed

启用模拟器侧分布式执行上下文.

enable_diagnostic_export

启用配置的diagnostic导出。

diagnostic_output_frequency

Diagnostic导出间隔.

diagnostic_output_path

Diagnostic输出路径.

diagnostic_reference_date

参考时间用于diagnostic时间坐标。

不存在隐式的自动检查点目录。要启用自动持久化，请显式映射所有必需的值：

from pathlib import Path
import tempfile

from relic.core.simulator import RELICSimulator

with tempfile.TemporaryDirectory() as tmpdir:
    checkpoint_dir = Path(tmpdir) / "automatic"
    runtime_config = {
        "time_step": 1800.0,
        "max_time": 3600.0,
        "enable_checkpointing": True,
        "checkpoint_directory": str(checkpoint_dir),
        "checkpoint_frequency": 3600.0,  # [s] simulation time
    }
    simulator = RELICSimulator(runtime_config)
    assert simulator.enable_checkpointing is True

在启用自动检查点时，checkpoint_directory=None 或非正的频率会被拒绝。手动的 simulator.create_checkpoint(checkpoint_path) 独立于自动开关，且始终要求一个显式且尚不存在的目标文件。

含义

key

完全限定参数标识符

value

当前参数值。

default

作为 metadata 保留的可选 declared fallback。

units

规范物理单位或 dimensionless（必填）。

dtype

声明的存储类型或张量数据类型（必填）。

bounds

包含端点的允许区间（必填）：数值 dtype 将无界的一侧写为 -inf 或 inf（YAML 中为 -.inf / .inf）；None（null）表示不适用区间，仅非数值 dtype（如文本值、布尔开关、列表或映射）可使用。数值端点、值和默认值必须为 YAML 数字（1.0e+7、1.0e-6）；1.0e7 或 1e-6 这样的文本会直接被拒绝，不执行转换。

category

用于验证和发现的参数分类（必填）。

description

参数的科学含义。

references

文献或权威来源标识符

tags

搜索和分组标签

dimension

物理量单位书写无关。

provenance

源与转化metadata

requires_grad

优化是否可以将值视为可训练的。

allowed_values

可选有限有效集 for 类别值

科学YAML预期应包含entriesvalue， units， dtype， bounds， category， description， references， tags， requires_grad，provenance物理常数仅属于relic\parameters\database\relic\physical\constants.yaml.

UnifiedParameterManager

在生产模式下（未设置 RELIC_SKIP_CALIBRATED），UnifiedParameterManager 从 relic\parameters\database\ 下的 138 个 YAML 文件（包含 4,642 个叶节点条目的 134 个权威 relic\ 文件，以及包含 109 个叶节点条目的 4 个 calibrated\ 覆盖文件，共计 4,751 个 YAML 叶节点条目）加载 4,643 个运行时参数，其中 810 个设置 requires_grad=True 的可训练参数可通过 get_trainable_parameters(with_gradients=True) 获取。

manager.get(
    key,
    default=None,
    namespace=None,
    units=None,
    expected_type=None,

)

参数

含义

key

参数键，可相对namespace解析。

default

返回值当键不存在且required为假时。

namespace

Namespace前缀在解决过程中使用。

units

请求的输出单位；请求的单位转换始终检查（读取操作没有验证开关，其他任何关键字都会引发 TypeError）。

expected_type

要求的 Python 或兼容张量的值类型；期望 float 时可将整数值拓宽，布尔值绝不视为数字，也不会对任何值进行窄化转换。

required

键不存在时抛出 KeyError。

bounds

可选访问时间 bounds. 超出范围的值被截断为 UserWarning.

get_parameter(key)返回ParameterSpec metadata对象，而非参数值。

from relic.parameters import get_global_manager

manager = get_global_manager()
density = manager.get(
    "relic.physical.constants.air.density_stp",
    required=True,
    units="kg m-3",
)
spec = manager.get_parameter("relic.physical.constants.air.density_stp")

print(density)
print(spec.units, spec.description)

其他管理操作包括set_value， register， list， snapshot， restore， diff， export， freeze， unfreeze， get_trainable_parameters和validate_parameters。在规范管理者上使用它们，不要创建第二个参数注册表。

Functor参数访问

在FunctorBase子类中使用Functor拥有的解析器：

from relic.core.functor import BiologicalProcessFunctor, FunctorMetadata
from relic.core.functor.functor_types import (
    ProcessCategory,
    SpatialScale,
    VariableKind,
)


class ParameterLookupDemo(BiologicalProcessFunctor):
    def __init__(self):
        metadata = FunctorMetadata(
            name="param_lookup_demo",
            description="Resolve a governed parameter via FunctorBase.",
            category=ProcessCategory.BIOLOGICAL_PROCESS,
            mathematical_expression="dx/dt = -alpha * x",
            references=["Executable documentation example"],
            parameters={
                "stochastic.weather.temperature.reversion_rate": "Mean reversion rate [day-1]"
            },
            input_variables=["x"],
            output_variables=["x"],
            spatial_scale=SpatialScale.POINT,
            variable_kind=VariableKind.STATE,
        )
        super().__init__(name="param_lookup_demo", config={}, metadata=metadata)

    def read_reversion_rate(self) -> float:
        param = self.get_parameter_value(
            "stochastic.weather.temperature.reversion_rate",
            required=True,
            units="day-1",
        )
        raw = param.value if hasattr(param, "value") else param
        return float(raw.detach()) if hasattr(raw, "detach") else float(raw)

    def forward(self, state, time, dt, **kwargs):
        return {}


demo = ParameterLookupDemo()
print(round(demo.read_reversion_rate(), 4))

FunctorBase.get_parameter_value(
    name,
    *,
    units=None,
    bounds=None,
    validate=True,
    namespace=None,
    source_order=("manager", "config"),
    expected_type=None,
    required=False,
)

source_order 控制 YAML 数据库（"manager"）与 Functor 配置（"config"，由 set_parameter_value 写入）之间的查找优先级；其他名称会引发 ValueError。没有调用方提供的默认值，也不动态注册：缺失参数为 None，required=True 则使缺失立即报错。

非Functor代码使用get_global_manager().get(...)。科学Functors不得直接调用全局管理器、硬编码科学后备方案或修改管理器缓存。

物理常数

from relic.utils.physical_constants import get_physical_constant

rho_air = get_physical_constant("air_density_standard")

get_physical_constant(name) 解析规范常量数据库；名称 air_density_standard 解析为 relic.physical.constants.air.density_stp（1.293 kg m-3），即 0 degC、101.325 kPa 下的干空气密度。这是参考常量，不是任意状态下的空气密度：需要当前空气密度的过程代码通过 relic.scientific.hydrosphere.utils.psychrometrics.compute_moist_air_density，由温度、压力和水汽压计算湿空气密度（如 PenmanMonteithET 所做的那样）。不要在 Python 或领域参数文件中重复定义常量。
